SHA-256, AES-CBC and three attacks, all written from scratch in Rust

Change one bit of the input and about half of the 256 output bits flip (avalanche). HMAC adds a key without the weaknesses of a naive sha256(key||msg).

The same plaintext blocks, encrypted two ways. ECB maps equal blocks to equal ciphertext, so structure leaks. CBC does not.

A server that only says "padding valid or not" lets an attacker decrypt any CBC message without the key. The attack runs here for real, one oracle query at a time.

A MAC built as sha256(secret||msg) can be extended by someone who never sees the secret. The forged message is accepted by the server. HMAC resists.

When the two primes are close together, Fermat factoring recovers them in a handful of iterations. Leave empty to generate a vulnerable key, or paste an n below 2^63.
